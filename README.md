# Birthday Wishes for Dad

A heartfelt birthday website you can personalize and share.

## Quick start

Open `index.html` in your browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080).

## Personalize it

1. **Name** — In `index.html`, change `Dad` in the hero to his name or nickname.
2. **Date** — Update the date in the hero section.
3. **Messages** — Edit the wish cards with your own words.
4. **Reasons** — Customize the four "Why You're the Best Dad" items.
5. **Photos** — Replace memory placeholders with real images:

```html
<div class="memory-photo">
  <img src="photos/trip.jpg" alt="Our trip together" />
</div>
```

Place images in a `photos/` folder and update the captions.

## Share

- Send the folder as a zip file
- Host on GitHub Pages, Netlify, or Vercel for a live link
- Open on a tablet or laptop as a surprise presentation
